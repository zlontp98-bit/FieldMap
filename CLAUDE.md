# FieldMap — памятка для новых сессий

Android-приложение для полевой работы (прокладка оптики): общая карта с объектами (папками), маркерами, линиями,
слоями кабелей и трубок, бобинами и фото. Пользователь пишет по-русски, отвечать по-русски.

## Где код

- **Весь проект лежит в архиве `fieldmap_v3.zip`** в корне репозитория (внутри — папка `fieldmap2/`).
- Рядом: `apk-port/` — перенос прототипа в страницу APK (`port.py` + `app_part.js`), сборка страницы в один файл
  (`bundle.py`, `loader.html`) и описание обновления (`manifest.py`); `apk-tests/` — проверки страницы APK (Playwright)
  и правил Firestore; `proto-tests/` — проверки самого прототипа.
- Основная ветка — **`main`**. Изменения делать в своей ветке и вливать в `main` через pull request (по просьбе пользователя).

Как менять код:
1. `unzip -q fieldmap_v3.zip -d <папка в scratchpad>` и править там (исходники страницы — `fieldmap2/web/`).
2. `python3 apk-port/port.py <прототип> <fieldmap2/web/index.html>` (если менялись port.py/app_part.js), затем
   `python3 apk-port/bundle.py <fieldmap2>` — пересобирает `app/src/main/assets/web/` (CI делает bundle сам ещё раз).
   Собрать архив обратно **с той же структурой** (`fieldmap2/` наверху):
   `cd <папка> && zip -qrX ../fieldmap_v3.zip fieldmap2`, скопировать в корень репозитория.
3. Коммит, push в свою ветку, pull request в `main`.

  web/js/store.js                сохранение, фото (IndexedDB), слияние правок, неотправленное, корзина
  web/js/sync.js                 вход через Google (Auth) и общая карта через Firestore (Sync), имена участников
  web/js/kml.js, firebase-config.js   KML; ключи Firebase и GOOGLE_WEB_CLIENT_ID
  web/version.json               версия страницы: web (число), name, minApk, minWeb, apkPush, notes {ru,it,en}
  app/src/main/assets/web/       ТО, ЧТО В APK (делает bundle.py, руками не править): index.html — загрузчик,
                                 app.html — страница одним файлом (js вставлены внутрь, window.FM_WEB = {v, name}), version.json
  app/src/main/java/com/fibra/fieldmapweb/MainActivity.java   WebView-оболочка, камера, файлы, вход через Google, обновление

  firestore.rules                окончательные правила Firestore (только вход через Google)

- **index.html** = прототип пользователя с claude.ai (артефакт «FieldMap прототип», slug `7d5b4188-d90b-43f1-a4ce-3c204990d0c8`,
  https://claude.ai/artifact/GUpDC2p6FmZbZaKoUfHenb) + то, что нужно приложению. Делается **скриптом**:
  `python3 apk-port/port.py <прототип index.html> <…/assets/web/index.html>`. Скрипт — список точных замен (каждая проверяет,
  что кусок найден ровно один раз; если прототип поменялся — падает и показывает, какую замену поправить) и вставка
  `apk-port/app_part.js` (файлы, страница «Общая карта», аккаунт, участники, присланные точки, `__onBack`, `appStart()`).
  Прототип читать через Artifact `read_artifact` частями (offset/limit; большие части сохраняются в файл, склеить по `offset`).
  Руками index.html не править — править port.py/app_part.js и пересобирать, иначе следующий перенос всё сотрёт.
- Что меняет port.py: заголовок страницы, убирает фото Бузаллы (`bgImg`) — сетка осталась только как запасная подложка для PDF;
  подключает js/*; данные через Store (`loadData/saveData`, `seed()` пустой); подложка Google схема/спутник (`gTile`, `crossOrigin`)
  и CARTO, вид карты с поворотом запоминается (`fieldmap_view`); GPS (синяя точка, ◎, `__onLocationPermission`);
  «Поделиться» маркером (AndroidBridge); `PhotoStore` → Store; `photoSrc` понимает `photo:<id>`; PDF/фото — `giveBlob` через
  AndroidBridge; меню: «Общая карта», «Участники карты», «Вы: имя»/«Войти через Google»; настройки: импорт/экспорт, аккаунт;
  `me()` — вошедший аккаунт с правами админа, люди/бригады прототипа скрыты (`initRoles` их чистит); переводы it/en новых строк.
- **Миграция с 3.x** (`S.apkV4`, при первом запуске): объекту без своего цвета пишется цвет его объекта (в 3.x он так и
  рисовался), `S.stageV1 = true` до миграций прототипа — ничего не становится проектом. Объекты в синих папках стали
  синими = «уже существует» (в отчёт не идут) — пользователя предупредили.
- **Данные** — объект `S`: `folders` (с `parentId`), `markers`, `lines` (`points`, `layers` со слоями кабелей/трубок, `via`),
  `reels`. Личное для телефона (не синхронизируется): `workMode`, `autoColor`, `log`/`logSnap` (журнал), `reportPlace`,
  цвета, `view` и т.п. Ключ localStorage `fieldmap_proto_v1` (не менять). У объектов `createdBy`/`updatedBy` = uid (ставит Store).
- **Фото**: в `photos` у маркера и линии — строка `photo:<id>` (старые и из галереи) или запись снимка камеры
  `{id, lat, lng, t, by, gps?, acc?}`. Картинки — в IndexedDB `fieldmap`/`photos` по id (Store.photoGet/photoPut);
  data:URL в данных Store сам переносит в IndexedDB. На сервере — документы `photos_{id}`; **подписка их не получает**,
  фото скачивается при открытии (`Store.photoGet` → `backend.getPhoto`). Что уже на сервере — `meta.sent[код]`
  (при обновлении с 3.x все старые фото считаются отправленными).
- **Синхронизация**: `maps/{код}/items/{вид}_{id}`, объект строкой JSON в поле `json`, побеждает более поздний `updatedAt`,
  удаление — `deleted:true`. Подписка — `where('kind', 'in', [folders, markers, lines, reels])`.
  Участники: `maps/{код}/members/{uid}` = `{uid, name, role, joinedAt, seenAt}` (пишется при подключении и смене имени),
  владелец — `maps/{код}/info/owner` = `{uid}` (создаётся один раз первым вошедшим). Журнал у каждого телефона свой:
  пришедшие изменения в журнал не пишутся (`onRemoteData` обновляет `logSnap`).
- **Вход**: только Google. Кнопка → `AndroidBridge.googleSignIn(GOOGLE_WEB_CLIENT_ID)` → Credential Manager → ответ в
  `window.__onGoogleSignIn({idToken, name, email} | {error})` → `Auth.signIn` → Firebase `linkWithCredential` (если был
  анонимный uid из 3.x) или `signInWithCredential`. Аккаунт запоминается в localStorage `fieldmap_account`
  (`{uid, google, name, email, named}`), имя спрашивается один раз. Общая карта без входа не подключается.
- **Firebase**: проект `fieldmap-afaf2` (europe-west8, тариф Spark). В базе тестовые карты от проверок: `BKA2L7HRCD`,
  `ZFDWU7PDQE` (09.11.2026) — можно игнорировать.
- **Карта-подложка**: Google схема/спутник (`mt*.google.com/vt/lyrs=m|y`, без ключа, отдают `access-control-allow-origin: *`)
  и белая CARTO. Фото Бузаллы и сетку как подложку пользователь просил **не возвращать**.
- **AndroidBridge** (JS → натив): `shareFile(name, mime, text)`, `shareBinary(name, mime, base64)`, `saveBinary(name, mime, base64)`
  (системное «Сохранить», ответ в `__onFileSaved(ok)`), `shareText`, `openMap`, `takeShared`, `requestLocationPermission`,
  `googleSignIn(clientId)`. Натив → JS: `__onBack`, `__onLocationPermission`, `__onSharedLocation`, `__onGoogleSignIn`, `__onFileSaved`.
  Камера: `<input capture>` → `onShowFileChooser` → `ACTION_IMAGE_CAPTURE` в кэш (FileProvider `photos/`); разрешение CAMERA
  не объявлено намеренно (тогда приложение камеры снимает без него).
- Страница грузится по адресу `file:///android_asset/web/index.html` — не менять (данные в хранилище WebView привязаны к адресу).
  Теперь по этому адресу лежит **загрузчик**: после `load` он берёт текст страницы у оболочки (`AndroidBridge.appHtml()`)
  и подставляет его в тот же документ (`document.open/write/close`) — адрес и хранилище остаются прежними. Запасной путь —
  XHR `app.html`.

## Обновление без APK (с 4.1)

- Файлы обновления — в релизах GitHub: `stable` (все телефоны) и `latest` (пробные версии; настройка «Пробные версии»,
  localStorage `fieldmap_channel = test`). В релизе: `FieldMap.apk`, `web.html` (= assets/web/app.html), `update.json`
  (`manifest.py`: web {version, name, url, sha256, minApk}, apk {versionCode, versionName, url, sha256, push}, minWeb, notes).
- Страница (`UPD` в app_part.js) при запуске, при возврате в приложение (раз в 3 ч) читает `update.json` через
  `AndroidBridge.fetchText` и предлагает «Обновить»: **web** — `downloadWebUpdate(url, sha256, version)` → файл в
  `files/webupdate/web-<v>.html` → `location.reload()`; **apk** — когда `web.minApk` больше versionCode телефона или
  `apk.push` → `downloadApk` → системная установка (разрешение REQUEST_INSTALL_PACKAGES).
  Оболочка качает только с `https://github.com/zlontp98-bit/FieldMap/releases/download/…` и сверяет sha256.
- Защита от плохого обновления: `appHtml()` считает запуски без `bootOk()` (страница зовёт его в `appStart`); три неудачи —
  обновление удаляется, версия помечается `bad` и больше не предлагается; работает встроенная страница.
  Обновление старее встроенной страницы (после установки нового APK) тоже удаляется.
- **Обязательная версия**: `minWeb` в `web/version.json`. Страница старее `minWeb` получает `Sync.block(…)` — общая карта
  не подключается, показывается «Нужно обновить приложение». Значение запоминается (`fieldmap_minweb`), подключение ждёт
  первую проверку (`Sync.setGate`, до 6 с). Телефоны 3.x и 4.0.x этого не умеют — их отсекают только правила Firestore.
- **Как выпускать**: поднять `web` и `name` в `web/version.json` (+ `notes`; если менялась MainActivity — ещё
  versionCode/versionName и `minApk`), port.py/bundle.py, архив, push. `actions_run_trigger` `build-apk.yml` c
  `inputs: {channel: test}` (или без inputs) → релиз `latest`: пользователь проверяет на своём телефоне с включёнными
  «Пробными версиями». По команде «выпускай всем» — тот же запуск с `inputs: {channel: stable}`.
  Номер `web` только растёт; `web` ≥ versionCode не обязательно, это разные счётчики (сейчас web 16 «4.3.1», versionCode 10, minApk 10 — в `latest`; `stable` ещё не выпускался)`). «Слои карты» считают цифры по активному объекту (`statFolders`).

## Защита работы (с 4.1) — store.js

- **Слияние списков**: слои линии (`layers`) и фото (`photos`) маркера/линии при одновременной правке объединяются.
  Store при сохранении ставит изменённому слою `ly.u = время`, удалённые слои/фото пишет в `it.gone = {'l:<id>'|'p:<id>': время}`,
  а самой записи — `it.ws = её updatedAt` (признак «записано 4.1+»; у старых версий ws не совпадает с updatedAt).
  `applyRemote`: если у объекта есть неотправленные правки (`unsent`) или пришедшая запись «современная» — `mergeLists`
  (остальные поля — из более новой версии, списки — объединение по id минус gone, одинаковый слой — с большим `u`);
  если итог полнее серверного — новая метка времени и отправка. Иначе — как раньше, более новая версия целиком.
  Пустой `ly.slack = {}` (страница дописывает его при показе карточки) правкой не считается (`pick`).
- **Неотправленное**: `meta.unsent[вид][id] = метка` ставится при сохранении (если есть карта), снимается, когда сервер
  подтвердил (`Sync.pushRec().then → Store.ack`, либо та же метка пришла в снимке; свои неподтверждённые записи Firestore
  помечает `pending` — они пропускаются). `meta.outbox` — фото, ещё не ушедшие на сервер. `Store.unsentCount()` →
  значок `#tbSync` в верхней полосе (ok / pend + число / wait / off).
- **Корзина**: IndexedDB `fieldmap_trash`/`items`, 30 дней, до 400 записей. Туда попадает: удалённое на этом телефоне
  (`save`), пришедшее удаление (`applyRemote`, в записи `by` — кто удалил), слои, пропавшие из линии, и «Заменить общей
  картой». Группа `g` — одно удаление (объект со всем содержимым). `trashRestore(keys)` возвращает объекты с прежним id,
  слой — с новым. Экран — `openTrash()` в app_part.js (меню ≡ → «Корзина»).
- **Кто добавил**: имена uid → имя берутся из участников карты при подключении (`Sync.nameOf`, localStorage
  `fieldmap_names`); в карточке — `authorText()`, в просмотре фото — `shotAuthor()`.

## Адрес по координатам (с 4.1.3) — `GEO` в app_part.js

- С 4.3 сначала геокодер телефона (`AndroidBridge.geocode(lat, lng, id)` → `android.location.Geocoder`, Locale it_IT,
  ответ в `__onGeocode(id, {road, house, quarter, city, postcode, line, country})`): это сервис Google, в нём есть номера
  домов, которых в OpenStreetMap часто нет (Via Borzoli в Генуе — без номеров). Для подписи берётся `line` без страны.
  Не ответил за 6 с — OpenStreetMap Nominatim (`reverse`, CORS открыт, не чаще раза в секунду — очередь), запасной — Photon (komoot).
  Ключ кэша с префиксом `2:` (старые ответы OSM без номеров не используются). В оболочке 10 ещё `setMediaPlaybackRequiresUserGesture(false)`.
  Ответы — в localStorage `fieldmap_geo` (до 400, ключ — координаты до 4 знаков + язык; язык ru → it, названия как на месте).
- Подпись фото камеры: третья строка — адрес места съёмки (`GEO.address`, ждём до 5 с; без сети — объект · название).
- Отчёт за день: место, если не вписано вручную, — `autoPlaceFor(день)`: в каждом объекте с работой за день первый
  поставленный маркер (по журналу), иначе начало линии со слоем; «город, район» через `GEO.place`, сохраняется в
  `S.reportAuto[день]` (личное). Вписанное вручную (`S.reportPlace`) главнее.

## Сборка APK

- Android SDK в этой среде нет; APK собирает GitHub Actions (`.github/workflows/build-apk.yml`): сам при push в `main`
  и вручную `actions_run_trigger` (`run_workflow`, `build-apk.yml`, ref = ветка). ~1–2 минуты, кладёт APK в релиз
  **`latest`** (заменяет предыдущий). Скачать `https://github.com/zlontp98-bit/FieldMap/releases/download/latest/FieldMap.apk`
  через curl, сверить sha256 с digest релиза и отправить файлом (SendUserFile).
- Перед каждой новой сборкой APK поднимать `versionCode`/`versionName` в `app/build.gradle` (сейчас 10 / 4.3);
  если менялась только страница — достаточно `web/version.json` (см. «Обновление без APK»).
  Подпись — `app/debug.keystore` (одинаковая, ставится поверх; SHA-1 `F9:83:10:43:CB:EF:30:93:34:75:66:59:DD:41:38:EC:96:01:7E:3D`).
- Сайты Google теперь открыты (dl.google.com, gstatic, firestore): MainActivity проверяется `javac` против
  `android-all` (Maven Central, `org.robolectric:android-all:13-robolectric-9030017`), `androidx.core` 1.12.0,
  `androidx.credentials` 1.3.0 и `googleid` 1.1.1 (classes.jar из AAR с dl.google.com/dl/android/maven2).

## Как проверять

  Firestore заменён ретранслятором в Node (`FIELDMAP_BACKEND_FACTORY`), вход Google — заглушкой (`FIELDMAP_AUTH_FACTORY`),

  (`assets/web/index.html`), обновление страницы, обязательная версия, обновление через APK (оболочка — заглушкой).
- Глобальные `Store`, `Sync`, `Auth` доступны из теста (`Store.data` — это `S` страницы).
- Правила Firestore — в эмуляторе Firebase: `apk-tests/rules/` (README там). 09.11.2026: переходные и окончательные —
